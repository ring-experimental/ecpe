# 타이틀·시스템 화면 조사

필드와 전투 밖 화면(첫 실행, 로고, 타이틀, 메인 메뉴와 그 하위, 시스템 팝업, 스태프롤)을 정리했다. 주소는 `client.bin` 파일 오프셋이고 게스트 주소는 +0x100000이다. 색은 `#RRGGBB`로 적는다. 원본 32비트 값은 `0xBBGGRR00`이다(`primitives.md`와 같다). 좌표는 512×320(`--width 512`)에서 잰 값이다. 가로 위치는 대부분 화면 가운데(폭/2) 기준이라 240 폭에서는 x가 136만큼 작다.

- 실행 폴더: `work/ui/run/title0`(첫 실행), `title1`(저장 없음), `title2`(사용자 저장 사본), `title3`(사본 + 해금 플래그), `title4`(첫 실행, 인자 기록). `ct_*.txt`는 calltree, `tp_*.txt`는 treepath, `args_*.txt`는 한 프레임의 함수 인자다.
- 스크린샷: `work/ui/survey/shots/title/*.png`.
- 인자 기록: native/ 밖(스크래치)에서 `tr.c` 사본의 `DEF` 매크로에 `at_enter(c, addr)`를 넣어 다시 빌드했다(`ecpe-at`). 이 빌드는 지정한 함수의 r0~r3과 `[sp..sp+16]`을 프레임 단위로 남긴다. 아래 SPR/FILL/RECT 좌표는 모두 이 기록에서 나왔다(✓). memdump로 확인한 필드도 ✓로 표시했다. 정적 분석으로만 읽은 것은 (정적)으로 적었다.

## 0. 공통

### 루트와 장면 표
- 앱 객체: `GOT[0x294]`(게스트 `0x14ee34`)가 가리키는 값은 `0x400020`이다(✓). `0x144b0()`도 같은 값을 돌려준다. `+0x48`이 월드 객체 **W**(`0x42bb6c`, ✓)다. `+0x60`에 1을 쓰면 게임이 끝난다(게임종료, 첫 실행 뒤 재시작).
- 틱 경로는 `0x6604 > 0x6720 > 0xbba0(W, input)`이다. `0xbba0`은 `W+0x2b0 + 4*W[+0xc]`에 있는 함수 `f(W, input)`를 부른다. 장면마다 함수가 하나뿐이고 vtable은 없다. 틱, 키 처리, 그리기를 한 함수에서 모두 한다. 표가 비어 있으면 장면 0으로 간다. 표는 `0xe390`이 채운다(memset 0x60 = 24칸). 처음 장면은 `W+0x14c & 0x20`(최적화를 마쳤는지)이 있으면 1(로고), 없으면 22(속도최적화)다.
- `W+0xc` = 장면, `W+0x10` = 장면의 하위 단계다. `0x103cc(W, 장면, 하위, 페이드?, [sp])`가 장면을 바꾼다.

### 자주 쓰는 그리기 함수(인자 기록으로 확인)
- `0x56ec(sheet, frame, x, y, [sp]0, [sp+4]0, [sp+8]=flip(0 없음, 1 좌우, 2 상하, 3 둘 다))`: 스프라이트 한 장. 이 안에서 `48d8 → 4798` 블리터가 돈다.
  - 타이틀 시트 = `W+0x45c` → `0x437cb0`(리소스 0x67, `e814`에서 `221dc`로 읽는다).
  - 공용 UI 시트 = `0x437380`(필드 메뉴 객체 `+0x14`와 같다).
- `0x5ae8(sheet, frame, x, y, 0,0,0, [sp+0xc]=blend*)`: 알파 섞기 스프라이트. 로고 페이드에 쓴다(정적).
- `0x54f0(sheet, frame, &w, &h)`: 프레임 크기. `0x54c8(sheet, frame)`: 폭.
- `0x1415c(x,y,w,h,[sp]=color)`: 채우기. `0x14184(...)`: 1px 테두리.
- `0x37a24(x,y,w,h,[sp]out,[sp+4]in)`: 강조 칸. out==in이면 기본값 out `#99adff`, in `#566ce7`(파란 선택 칸)을 쓴다.
- `0x261d4(rect*, c1, c2)`: 세로 그라데이션.
- `0x14274(rect*)`: 3겹 창틀. 바깥부터 `#f7dba5`, `#948a9c`, `#081442`. lr `1429c/142b4/142cc`.
- `0x2ff80(x,y,w,h)`: 4겹 창(`#222540`, `#f0d9a3`, `#948a9c`, `#0d1540`) + 바탕 `#30305c`.
- `0xf748(W, &x,&y,&w, ..., 제목)`: 게임정보·랭킹 패널. 제목칸(197,142,118×19) 아래에 본문칸(197,163~165,118×~90)을 놓는다.
- 글:
  - `0x3a1c(gfx,x,y,str)`: 한 줄. DrawString y = 인자 y + 9.
  - `0x3bf0(gfx,x,y,w,[sp]h,[sp+4]str,[sp+8]flags)`: 상자 안 글. flags 4는 줄바꿈 왼쪽 정렬, 0x122/0x102는 가운데 정렬.
  - `0x14240(x,y,w,h,[sp]str,[sp+4]flags)`: 3bf0에 앱 gfx를 넣어 부른다.
  - `0x3f14(gfx,color)`: 글 색을 정하고 이전 색을 돌려준다.
- 키 코드: `0x61d4(input)`가 이번 프레임에 눌린 키를 돌려준다. 내부 코드 = WIPI 코드 + 0x20이다.
  - 위 `0x1f`, 아래 `0x1e`, 왼쪽 `0x1d`, 오른쪽 `0x1c`, OK `0x1b`(RSK도 `0x1b`), CLR `0x10`
  - 숫자 `'0'..'9'` → `0x50..0x59`, `*` `0x4a`, `#` `0x43`
  - 메뉴는 숫자 2/8/4/6/5를 방향과 OK로도 받는다.

## 1. 속도최적화(첫 실행) — 장면 22 `0x10ef0`
- 도달: 저장 없이 띄우면 바로 나온다(0.5초 안에 끝남). 스크린샷 `속도최적화.png`.
- 하위 0(16프레임, 카운터 `W+0x15c`):
  - 진행 막대: 클립 폭 w, 높이 h 기준으로 x=w/8, y=(h-8)/2. 512에서 (64,156)이다.
  - FILL(65,157,382,6,`#30305c`) + RECT(64,156,384,8,흰색) + BEVEL(65,157, 382*n/15, 6, 흰색, `#ff0000` 빨강).
  - 글 「속도최적화...」(GOT 0x224)는 (64, 막대 y - 줄높이 - 2)에 흰색으로 쓴다. ✓
- 끝나면 `W+0x14c |= 0x20`, `12598`로 gopt.sav를 쓴다. 걸린 시간이 2140ms를 넘으면 퀵모드를 켜고(0x40|0x80|0x400|0x800000) 속도를 4로 둔다. 이어서 하위 1로 간다.
- 하위 1 「재시작 안내」(`재시작안내.png`):
  - `14240(16,32,W-32,H-64, GOT 0x228, 0x104)`: 「게임종료 후 재시작해야 합니다.⏎게임속도가 느릴경우, 메인메뉴 환경설정에서 퀵모드를 On으로 변경하세요.」 DrawString (16,156),(16,170) ✓
  - 「OK : 계속」(GOT 0x22c)은 `14240(0,H-16,W,16,…,0x22)`로 그린다. 11프레임 주기로 7프레임 보이고 4프레임 숨는다(`W+0x49c % 11 > 6`이면 숨김).
  - OK/CLR을 누르면 앱 `+0x60=1`로 종료한다. 네이티브는 자동 재시작한다.

## 2. 로고 — 장면 1 `0xe5e4`
- 도달: 시작 직후 약 3초. `로고_넥슨.png`, `로고_펀터.png`.
- 바탕은 흰색이다(`467c(0,0,0xffffff00)`).
- 하위 1: NEXON MOBILE = 타이틀 시트 fr7. 화면 가운데(`W+0x494`, `+0x498`)에 둔다.
- 하위 2: Funter 로고 fr4, 「Funter Studio」 fr5, 「Present」 fr6을 세로로 쌓는다. 각각 가운데 정렬이고 y는 중심 -40, +h-28, +h-12다.
- 그리기는 `0x5ae8` 알파 블릿이다(정적). 인자 기록에는 안 잡혔다(미확인).

- 아무 키나 누르면 다음 로고로 넘어간다. 하위 3에서 흰 화면으로 1초를 기다린 뒤 장면 2로 가고 BGM 0을 튼다(`11aec(W,0,1,0x300)`).
