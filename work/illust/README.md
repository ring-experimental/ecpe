# 리마스터 일러스트

원본 초상화(UI 시트 프레임 60~68)를 `에픽크로니클자료/epic/프로필샷`의 원화로 바꿔 보인다. 환경설정의 「일러스트 HD/도트」 버튼
(F4, 기타 설정 창의 체크, ui.ini `illust`)으로 켜고 끈다. 켜면 대사창·메뉴 카드·스테이터스 등 그 프레임을 떼어 쓰는 모든 새 UI 화면이
고해상도 그림을 쓴다. 원작 그리기(F2)에서는 바뀌지 않는다.

`src_f068.png`, 흰 바탕)과 화풍 참고용 `gpt/io.png`를 ChatGPT 이미지 생성에 함께 올렸다. 프롬프트:
「첫 번째 이미지는 옛 휴대폰 게임의 도트(픽셀) 초상화를 확대한 것이고, 두 번째 이미지는 같은 게임 다른 캐릭터의 원화다. 첫 번째 도트
초상화를 두 번째 원화와 같은 화풍(손그림 선화 + 부드러운 채색)의 고해상도 일러스트로 다시 그려줘. 인물의 얼굴 생김새·표정·머리 모양과
색·옷·포즈·구도·잘린 위치(상반신 아래가 잘린 그대로)는 도트 그림과 똑같이 유지하고, 인물을 새로 지어내거나 구도를 바꾸지 마. 두 번째
이미지의 인물은 화풍 참고용일 뿐이니 그리지 마. 배경은 완전히 투명한 PNG(알파 채널)로, 첫 번째 이미지와 같은 비율로 출력해.」
결과 `gpt/nihat_young.png`, `kirien.png`를 `fit.py`로 프레임에 맞췄다. UI 시트에서 40px이 넘는 초상 프레임은 60~68뿐이다(나머지는 아이콘·글자).

### 원작에 초상이 없는 인물(대사창만)

얼굴 없이 말하는 대사의 화자 이름(게임 NPC 이름 표 그대로)이 아래와 같으면 대사창 얼굴 칸에 그림을 띄운다. 도트로 두면 원작처럼 얼굴이
없다. 그림은 오른쪽을 보게 두고, 대사창 오른쪽 칸이면 뒤집어 안쪽을 보게 한다.

| 화자 이름 | 프로필샷 | 파일 | 원화 방향 |
|---|---|---|---|
| 겐나드 | 겐라드.jpg | illust_gennad.png | 왼쪽 → mirror |
| 모아드 | 모아드2.jpg(모아드.jpg보다 크고 핏자국이 없다) | illust_moad.png | 왼쪽 → mirror |
| 아케인 | 아케인.jpg | illust_arcane.png | 오른쪽 |
| 텔러 | 텔러.jpg | illust_teller.png | 오른쪽 |
| 하멜린 | 하멜린.jpg | illust_hamelin.png | 왼쪽 → mirror |

`npc.py gpt/<이름>.png out/illust_<이름>.png [mirror]`: 투명 테두리를 잘라 높이 64dp × 8배로 맞춘다(폭 100dp까지). 알파 40 미만은
지운다(겐나드 정리본은 배경 전체에 옅은 알파가 남아 있었다).
이름은 script.bin이 아니라 NPC 이름 표(게임 메모리 0x44d…)에서 확인했다(원작 표기는 겐라드가 아니라 겐나드).

## 만드는 법

1. `gpt/<이름>.png`: 프로필샷을 ChatGPT 이미지 생성에 올려 정리했다(2026-11-11). 프롬프트:
   「첨부한 캐릭터 일러스트를 정리해줘. 인물 바깥의 거친 연필 스케치 선, 밑그림 선, 얼룩, 종이 잡티, 삐져나온 선만 깨끗이 지우고,
   캐릭터의 얼굴·포즈·구도·잘린 위치·색·채색 스타일은 그대로 유지해. 다시 그리거나 얼굴을 바꾸지 마. 배경은 완전히 투명한
   PNG(알파 채널)로, 원본과 같은 비율로 출력해.」
2. `frames/f0NN.png`: 원본 프레임. `ECPE_FACEDUMP=<폴더>`로 띄우고 필드에 서면 UI 시트의 모든 프레임을 PPM으로 남긴다
   (restored/ui_dialog.c face_dump).
3. `fit.py gpt/<이름>.png frames/f0NN.png out/illust_<이름>.png`: 원본 도트는 원화를 줄여 찍은 것이라, 원화를 줄인 격자에서
   도트와 가장 맞는 배율·자리·좌우 뒤집기를 찾아 프레임 테두리에 꼭 맞게 잘라 8배로 남긴다(게임에서는 프레임이 놓인 자리에
   그대로 겹친다). 맞춤 확인은 도트와 반씩 섞어 보면 된다.
4. NPC는 3 대신 아래 `npc.py`.
5. `make`가 `out/illust_*.png`를 build/ui로 복사한다(Android 팩에도 들어간다).

gpt/, frames/, out/은 원본 파생물이라 저장소에 넣지 않는다(.gitignore).

## 동작

- `restored/illust.c`가 0x56ec(합성 프레임 그리기)를 감싼다. 새 UI가 그림을 떼는 중(scratch)에 메뉴 시트의 60~66이 그려지면
  같은 인자로 전체 클립 시험 그리기를 해 테두리를 재고, 그 테두리와 그릴 때의 클립을 `ui_illust_mark`로 알린다.
- `host/ui.cpp` `illust_sprite`: `ui_sprite`/`ui_sprite_trim`이 뗀 칸이 표시된 자리에 걸치면 원래 화소 대신 그림 파일에서 같은 자리를
  (뒤집기 포함) 잘라 촘촘한 텍스처로 만든다. 문서에서의 크기(dp)는 원래 그림과 같아 배치는 그대로고 부드럽게 줄여 그린다.
